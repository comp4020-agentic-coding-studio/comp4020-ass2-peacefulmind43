# Process overview

## What I built

SLOP3251, The Formal Theory of Poker, is a level 3 course. The obvious course for a poker brief is a course that teaches you to play better. I did the opposite. This course is for people who already believe their instinct at the table, and want to know which part can become a proof. Every week takes one thing poker players believe (a hand is worth playing, a fold was correct, an opponent is bluffing), and proves it or says it is wrong. This decision decided many things the brief left open. Strategy advice is not included. A wrong claim is also a result, so every week revises earlier weeks instead of starting again. It also decided the rule I wrote in CLAUDE.md before any content existed ([`583b199`](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-peacefulmind43/commit/583b199)): every number in a session must come from a harness that computed it, not from my memory.

## How I got here

The normal order is to write content first and check it later. I used the other order when I could. The ICM calculator ([`0cd5918`](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-peacefulmind43/commit/0cd5918)) is a separate commit, before the week 10 content that uses its numbers. The Monte Carlo simulator is not like this. It was committed together with week 1 ([`ad47176`](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-peacefulmind43/commit/ad47176)), so the order is not so clear there. But the important part is still true: the equity number on the page came from the simulator, and `spec/poker-equity.test.ts` computes it again, it does not just copy it.

The more difficult question is how to know the solver is correct when there is no answer to compare with. So I ran the CFR solver ([`c52eaa4`](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-peacefulmind43/commit/c52eaa4)) on Kuhn poker first, because Kuhn poker already has a published solution. The spec checks the game value −1/18 and the whole published strategy family: the lowest card bluffs with probability α in [0, 1/3], the highest card bets with 3α, the middle card calls with 1/3 + α. Only after these checks passed, week 12 used the same solver on a four-rank game which has no published answer ([`b458268`](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-peacefulmind43/commit/b458268)). If the solver has a bug, it will fail on the game with a known answer. On the four-rank game it will just give a wrong number that still looks reasonable.

One smaller decision is similar. The starter template put the only slide deck in week 1, and keeping it there is easier. But week 1 is only an introduction. A deck is more useful where the reader must follow a calculation step by step, so I moved it to week 3, the week about exact outs and pot odds, where each slide shows one line of the calculation ([`0900945`](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-peacefulmind43/commit/0900945)).

The worst part of the process is my own mistake. One question asked me three things together: the image style, the policies page, and this file. I rejected it, then typed "keep going". My meaning was stop showing me this popup, not decide everything by yourself, but it understood the second meaning. It chose the artwork style by itself, deleted two photos, wrote the policy text, and pushed this file without asking me again. I made it revert both commits ([`a79517d`](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-peacefulmind43/commit/a79517d), [`f6bb80a`](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-peacefulmind43/commit/f6bb80a)), then we did every decision again one by one, and I checked every result myself. Two smaller decisions also appeared: it made original SVG artwork instead of using the starter images, and it refused to use Minecraft's Steve and Alex design for staff photos because of copyright, and deleted those photos instead ([`a5d096d`](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-peacefulmind43/commit/a5d096d)). After this, every decision is confirmed with me first, before it is written or pushed.
